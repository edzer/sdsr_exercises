Exercise 5.3.

the AREA variable

import geopandas as gpd
import numpy as np
from pyproj import Geod

nc = gpd.read_file("data/nc/nc.shp")
print(nc["AREA"].head(10).tolist())
# [0.114, 0.061, 0.143, 0.07, 0.153, 0.097, 0.062, 0.091, 0.118, 0.124]

# helper: yield exterior rings of a (Multi)Polygon as (lon, lat) lists
def rings(geom):
    if geom.geom_type == "Polygon":
        yield list(geom.exterior.coords)
    else:
        for g in geom.geoms:
            yield list(g.exterior.coords)

def area_geodesic(geom, ellps):
    geod = Geod(ellps=ellps)
    return sum(
        abs(geod.polygon_area_perimeter([c[0] for c in r], [c[1] for c in r])[0])
        for r in rings(geom)
    )

a_sph = nc.geometry.apply(lambda g: area_geodesic(g, "sphere"))   # spherical
a_ell = nc.geometry.apply(lambda g: area_geodesic(g, "WGS84"))    # ellipsoidal
print(np.round(a_ell.head(10) / 1e6, 2).tolist())  # km^2
# [1137.39, 611.08, 1423.49, 694.55, 1520.74, 967.73, 615.94, 903.65, 1179.35, 1232.77]
print("cor(a_ell, a_sph):", round(np.corrcoef(a_ell, a_sph)[0, 1], 6))
# cor(a_ell, a_sph): 1.0

Also, there are deviations from the 1:1 regression line. Could these be explained by the rounding of AREA to three digits? If rounding to three digits was the only cause of spread around the regression line, we would expect a residual standard error similar to the standard deviation of a uniform distribution with width .001, which is

but the one obtained int he regression is three times larger. Also, the units of AREA would be 1e10 \(m^2\), or 1e4 \(km^2\), which is odd and could ring some bells: one degree latitude corresponds roughly to 111 km, so one “square degree” at the equator corresponds roughly to \(1.11^2 \times 10^4\), and at 35 degrees North roughly to

We can compute “square degree” area by using the \(R^2\) area routines, e.g. obtained when we set the CRS to NA:

  • R
  • Python
nc2 = nc
st_crs(nc2) = NA
nc2$area = st_area(nc2) # "square degrees"
plot(area ~ AREA, nc2)
abline(0,1)
cor(nc2$area, nc2$AREA)
# [1] 0.999983
summary(lm(area ~ AREA, nc2))
# 
# Call:
# lm(formula = area ~ AREA, data = nc2)
# 
# Residuals:
#        Min         1Q     Median         3Q        Max 
# -5.471e-04 -2.265e-04 -9.880e-06  2.714e-04  4.594e-04 
#

#              Estimate Std. Error  t value Pr(>|t|)    
# (Intercept) 7.436e-05  7.965e-05    0.934    0.353    
# AREA        9.996e-01  5.882e-04 1699.395   <2e-16 ***
# ---
# Signif. codes:  0 '***' 0.001 '**' 0.01 '*' 0.05 '.' 0.1 ' ' 1
# 
# Residual standard error: 0.0002879 on 98 degrees of freedom
# Multiple R-squared:      1,   Adjusted R-squared:      1 
# F-statistic: 2.888e+06 on 1 and 98 DF,  p-value: < 2.2e-16
import numpy as np
import statsmodels.api as sm
import matplotlib.pyplot as plt

# "square degree" area: treat lon/lat as planar and use the shoelace formula
def area_sqdeg(geom):
    if geom.geom_type == "Polygon":
        xs, ys = np.array(geom.exterior.coords)[:, 0], np.array(geom.exterior.coords)[:, 1]
        return 0.5 * abs(np.sum(xs * np.roll(ys, -1) - np.roll(xs, -1) * ys))
    else:
        return sum(area_sqdeg(g) for g in geom.geoms)

sqdeg = nc.geometry.apply(area_sqdeg)
print("cor(sqdeg, AREA):", round(np.corrcoef(sqdeg, nc["AREA"])[0, 1], 6))
# cor(sqdeg, AREA): 0.999983

model2 = sm.OLS(sqdeg, sm.add_constant(nc["AREA"])).fit()
print("lm slope:", model2.params.round(6).tolist())
# lm slope: [7.4e-05, 0.999554]
print("residual SE:", round(np.sqrt(model2.mse_resid), 6))
# residual SE: 0.000288

fig, ax = plt.subplots()
ax.plot(nc["AREA"], sqdeg, "o")
ax.set_xlabel("AREA")
ax.set_ylabel("square degrees")
plt.show()

We now get a much better fit, a near perfect correlation, and a regression standard error that corresponds exactly to what one would expect after rounding AREA to three digits.

A further “red flag” against the constant (1e10) conversion hypothesis is the spatial pattern of the regression residuals obtained by the first approach:

  • R
  • Python
nc$resid = residuals(lm(area2 ~ AREA, nc))
plot(nc["resid"])
import matplotlib.pyplot as plt

nc["resid"] = model.resid
fig, ax = plt.subplots()
nc.plot(ax=ax, column="resid", legend=True, cmap="coolwarm")
ax.set_title("residuals of area2 ~ AREA")
plt.show()

these residuals clearly show a North-South trend, corresponding to the effect that the Earth’s curvature has been ignored during the computation of AREA (ellipsoidal coordinates were treated as if they were Cartesian). “Square degrees” become smaller when going north.

The “unit” of the AREA variable is hence “square degree”. This is a meaningless unit for area on the sphere, because a unit square degree does not have a constant area.

Exercise 5.4

type of area

“area” is of type aggregate: it is a property of a polygon as a whole, not of each individual point in the polygon. It is extensive: if we cut a polygon in two parts, the total area is distributed over the parts.

def interpolate_aw(sources, values, targets, extensive):
    out = []
    for tgt in targets:
        num = 0.0
        for src, v in zip(sources, values):
            ov = tgt.intersection(src)
            if ov.is_empty:
                continue
            ov_area = ov.area
            if extensive:
                num += v * ov_area / src.area
            else:
                num += v * ov_area
        out.append(num if extensive else num / tgt.area)
    return out

print("extensive:", interpolate_aw(g, [1, 2, 4, 8], targets, True))
# extensive: [1.75, 15.0]
print("non-extensive:", interpolate_aw(g, [1, 2, 4, 8], targets, False))
# non-extensive: [2.3333333333333335, 3.75]
